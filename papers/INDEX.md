# Source papers

Every file is `YYYY_Author_Short-title.pdf`. The original thirteen also have a text extract in `data/text/` with the same name.

Three downloads were the same document as a file already here, so only one copy was kept:

- `Direct Reduction of Iron Process.pdf` was byte-for-byte the TERI 2021 report, now `2021_TERI_Energy-efficient-DRI-options.pdf`.
- The second CEEW file (`Nitturu et al 2`) was byte-for-byte the first.
- The 2024 Elsevier download of Gaurav was the same article, *Energy* 301, 131512, as the copy already in the project. Kept as `2024_Gaurav_WHR-preheating-and-power.pdf`.

The mid-sem report and the IITD instructions PDF are in `reports/`. They are not source papers.

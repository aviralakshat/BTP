# Project management

Planning, decisions and the research trail. These files record how the model got to where it is. The current state of the model is in [`../models/`](../models/README.md); the change history is in [`CHANGELOG.md`](../../CHANGELOG.md).

| File | Contents |
|---|---|
| [`PROJECT_MASTER_PLAN.md`](PROJECT_MASTER_PLAN.md) | The phased plan for the digital twin and decision product: scope, phases, acceptance criteria |
| [`PLAN_DEVIATIONS.md`](PLAN_DEVIATIONS.md) | Where the repository departs from the plan, and why. Where the two disagree, the repository is the one to follow. |
| [`OPEN_QUESTIONS.md`](OPEN_QUESTIONS.md) | Decisions still open: real plant data, the analyst's language-model provider, the official carbon-price case |
| [`sessions/`](sessions/) | Working-session logs |
